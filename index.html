Memory

Auto-run (no tap)

Choose what Starlx may do instantly when you ask. Calls, texts, timers, alarms and links always need a tap. While web search is active, only the phone option auto-runs.

Smart home commands

One per line: name = https://link. Add GET or POST before the link if needed. Starlx can then run them by name, for example from a Home Assistant, IFTTT or Make webhook. Put {value} in a link where a value should go, like a volume level. Keep these links private. They are not included in backups.

Backup

Backs up memory, tasks, personality, settings and chat. Set a passphrase to also include your API keys and command links. The file is then encrypted, so it is safe to email to yourself. Remember the passphrase, because it cannot be recovered.
